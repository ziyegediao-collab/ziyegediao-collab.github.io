Projects

Focus Timer

A Pomodoro timer that runs entirely in the browser. It supports focus / short break / long break modes, custom durations, a task list for the current session, and a daily counter of finished focus sessions. Tasks and settings are saved in localStorage, so they survive a page refresh, and a short beep (Web Audio API) marks the end of each interval.

Tech: vanilla JavaScript, Web Audio API, localStorage · Source code
