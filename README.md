# Oliver's personal website

A small static site, hand-written in HTML/CSS/JavaScript and published with
GitHub Pages at https://ziyegediao-collab.github.io

## Contents

- `index.html` — homepage: about, projects, contact.
- `focus-timer/` — a Pomodoro-style focus timer that runs entirely in the
  browser (vanilla JavaScript, Web Audio API beep, tasks and settings kept
  in `localStorage`).

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```
